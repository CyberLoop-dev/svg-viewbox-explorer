## 🧭 Overview

Adjust an SVG viewBox and preserveAspectRatio mode to see how the same drawing scales and aligns inside a fixed viewport. The lab updates the real SVG attributes and shows the values being applied.

## ✨ Features

- ✨ Edit viewBox width and height.
- ✨ Compare meet, slice, and none scaling modes.
- ✨ Choose xMin, xMid, or xMax alignment.
- ✨ Inspect the live SVG attribute values.

## 🎬 Demo

Run the local app and use the controls with the included example or your own input. No hosted demo is claimed; processing stays in your browser.

## 🚀 Quick Start

```bash
npm start
```

Open **http://127.0.0.1:4173**.
